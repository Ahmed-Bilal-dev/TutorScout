# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.

# TutorScout — A Web-Based Tutor Finder and Booking System

TutorScout is a web-based platform developed as a Final Year Project by BSCS students at Federal Urdu University of Arts, Science and Technology (FUUAST), Karachi.

The purpose of TutorScout is to make it easier for students to find suitable tutors without relying only on personal references or scattered social media posts. Students can explore tutor profiles, search by subject and location, compare available teaching options and fees, and submit booking requests online.

The platform provides separate dashboards for students, tutors, and administrators. Students can manage their booking requests and submit reviews, while tutors can manage their profiles and respond to booking requests. The administrator can access the available user and booking management features.

TutorScout is built using **React.js, Vite, Tailwind CSS, Firebase Authentication, and Cloud Firestore**. The application is deployed on Netlify and is designed to work across desktop, tablet, and mobile devices.

**Live Website:** https://tutorscout.netlify.app/
